== Aktueller Branch s3-aws

Aktiv sind nur Sodata und APISIX. Das Portal liest aus dem AWS-Testbucket
`ch.so.daten-test` in `eu-central-1`. Einstieg: `./scripts/up.sh`, Portal unter
`http://localhost:8081/`, lesender Check mit `./scripts/smoke-test.sh`.
Siehe xref:start.adoc[Start] und xref:konfiguration.adoc[Konfiguration].
